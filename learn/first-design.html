Learn / Getting started

Your first design

This walkthrough takes you from a blank canvas to a finished image. It takes a few minutes and uses only the basic tools.

Start from a blank canvas or a template

When you open the studio you get a blank white canvas of 1080 × 1080 pixels, shown at 50% zoom.

If you would rather start from a ready-made design, click Designs in the toolbar and double-click a template. Everything in it stays editable. See Designs.

Note: Opening a template replaces what is on your canvas.

1. Set the canvas size

With nothing selected, the panel on the right shows Canvas Properties.

  1. Type a new value in Width and Height.
  2. Press Enter or click outside the box to apply it.

You can also type basic math such as 1080 * 2. See Canvas properties.

2. Choose a background color

Next to Color, click the swatch to open the color picker, or type a hex value such as FFEECC or even a CSS color name like 'red', 'coral', 'aliceblue', etc. and press Enter.

3. Add text

  1. Click Text in the toolbar.
  2. Pick a font category at the top of the menu, or search for a font.
  3. Double-click a font in the list.

A new text layer appears in the middle of the canvas, already selected. It shows the font's name as sample text.

4. Change the words

  1. With the text selected, right-click it and choose Edit text, or use its keyboard shortcut.
  2. Type your words in the box on the right. Press Enter for a new line.
  3. Click Save Edit, or press Escape to finish.

Note: Double-clicking a text layer does not open the editor. Use the right-click menu or the keyboard shortcut.

5. Style the text

Use the icons along the bottom of the text panel. Text Format holds the font size, color, spacing, case and alignment. Text Style adds an Outline, a Glow or a Shadow. See Text properties.

6. Add an element

  1. Click Elements in the toolbar.
  2. Double-click a shape, icon, graphic or photo to add it to the canvas.

A single click does not add anything. See Elements.

7. Arrange your layers in canvas

  • Drag a layer to move it.
  • Drag a handle to resize it. Hold Shift to keep its proportions.
  • Hover just outside a corner handle until the cursor curves, then drag to rotate.

See Selecting and moving and Layers.

8. Export your design

  1. Click Save in the toolbar.
  2. Type a Title. It becomes the file name.
  3. Choose a format under File Export: PNG, JPEG, WEBP or PDF.
  4. Click Download, or use its keyboard shortcut.

See Export.

Tip: To keep working on the design later, also click Save File. It downloads a Wondr file you can open again. See Wondr files.

Your work is also autosaved while you design. See Autosave.
