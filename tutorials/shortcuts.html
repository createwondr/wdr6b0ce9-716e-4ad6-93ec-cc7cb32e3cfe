Keyboard shortcuts

Note: On a Mac, Wondr uses Cmd (Command) wherever Windows uses Ctrl, and every shortcut below shows both. Two differ: hide is Cmd + Shift + H, because macOS keeps Cmd + H for hiding the browser, and the delete key deletes.

Save and export

  • Ctrl + S (Mac: Cmd + S): save your project as a Wondr file to your computer. Works even while typing. See Wondr files.
  • Ctrl + D (Mac: Cmd + D): download your export in the format and size set in the Save menu. See Export.

Edit

  • Ctrl + Z (Mac: Cmd + Z): undo.
  • Ctrl + Shift + Z (Mac: Cmd + Shift + Z): redo.
  • Ctrl + C (Mac: Cmd + C): clone the selected layers, not copy them. The copies appear right above the originals.
  • Ctrl + V (Mac: Cmd + V): paste an image from your clipboard. It is added to your Uploads and to the canvas.
  • Ctrl + X or Delete (Mac: Cmd + X or delete): delete the selected layers, or the selected pictures in the Uploads gallery. It does not cut them.
  • Ctrl + E (Mac: Cmd + E): edit the selected text. Press it again to save the edit.
  • Ctrl + H (Mac: Cmd + Shift + H): hide or show the selected layers.

Select and move

  • Ctrl + A (Mac: Cmd + A): select everything, or deselect it if everything is already selected. It acts on what is under your pointer: the canvas, the Layers menu or the Uploads gallery.
  • Ctrl + click (Mac: Cmd + click): add a layer to the selection, or remove it. Works on the canvas, in the Layers menu and in the Uploads gallery.
  • Shift + click: in the Layers menu or the Uploads gallery, select a range.
  • Arrow keys: move the selected layers by 2 pixels.
  • Shift while resizing: keep the proportions.
  • Shift while rotating: turn in 15 degree steps.

View

  • Ctrl + mouse wheel (Mac: Cmd + scroll): zoom in or out by 2% at a time. Over the canvas it zooms toward your pointer. Pinching on a trackpad also zooms. Your browser's own zoom keys, Ctrl + Plus and Ctrl + Minus (Mac: Cmd + Plus and Cmd + Minus), zoom the whole page instead.
  • Escape: close one thing at a time, from the innermost: a swap, the eyedropper, the color picker, a right-click menu, an open list, and finally the left menu.

Double-click

  • A template opens it.
  • A pattern, element, upload or font adds it to the canvas.
  • A layer's name in the Layers menu renames it.

In boxes

  • Enter: apply a value. Number boxes accept sums, units and percent, for example 200 + 50 or 50%.
  • Up and Down arrows: change a number by 1.
  • Enter in a search box picks the first suggestion.
  • Delete in a search box clears it.
  • Enter in the text editor adds a new line, and Escape saves and closes it.
