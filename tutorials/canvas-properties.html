Canvas properties

The Canvas Properties panel controls the size and background of your design. It shows on the right whenever nothing is selected and the view is in 2D.

To get back to it, click an empty spot of the work area. That clears the selection.

Width and height

Type a size in pixels in Width and Height, then press Enter or click outside the box. Each side can be from 2 to 4096 pixels. A new canvas is 1080 × 1080.

  • You can type basic math, for example 1080 * 2 or (1920 / 2).
  • 50% sets the box to half of its current value.
  • half and quarter set the box to half or a quarter of its current value. max sets it to 4096 and min to 2.
  • You can also use rem units as part of basic math (1rem is 16 pixels), for example 1080 + 2rem or 50% - 1rem.
  • Use the Up and Down arrow keys to change the value by 1.

A size change is a single undo step. It also resets Output Width and Output Height in the Save menu to the new size. See Export.

Note: Sizes are in pixels only. There are no size presets or print units, so look up the pixel size you need first.

Lock Aspect Ratio

Turn on Lock Aspect Ratio to keep the shape of the canvas. When you change one side, the other follows at the same ratio.

Resize direction

The menu at the top of the panel, Resize to Center by default, decides where the space is added or removed when you change the size. Your layers keep their place against the side that stays put.

  • Resize to Center: the change is shared equally on both sides.
  • Resize to Left / Right / Top / Bottom: space is added or removed on that side.
  • Resize to Top Left, Top Right, Bottom Left, Bottom Right: space changes on both sides of that corner.

Pattern layers always refit to the new size.

Tip: Picking an option applies it straight away using the current width and height. Choose the direction first, then type the new size.

Background color

Next to Color, type a hex value such as FFFFFF, or click the swatch to open the color picker. The canvas background can be a solid color or a linear or radial gradient. See Basic properties for how the color picker works.

In 3D view

In 3D view this panel is replaced by 3D Environment. Switch back to 2D to change the canvas size. See Zoom, 2D and 3D view.
